# 🫀 CVS Histology Review & Quiz

An interactive web-based histology review tool focused on the Cardiovascular System (CVS). This project is designed to make studying histology more engaging and effective for medical students.

## ✨ Features
- **Interactive Quiz:** Test your knowledge and recall of CVS histological structures.
- **Instant Audio Feedback:** Features custom sound effects (`correct.mp3`, `wrong.mp3`) for immediate assessment.
- **User-Friendly Interface:** Clean, responsive design for studying on the go.
- **Live Access:** Fully hosted on GitHub Pages for instant access without installation.

## 🎯 Target Audience
Created specifically to help first-year medical students, particularly at Al-Azhar University, review their histology curriculum efficiently before exams.

## 💻 Tech Stack
- HTML5
- CSS3
- JavaScript
